# taller api covid JFMO

APK disponible en releases

# Ejecución

Para ejecutar el proyecto desde PC, se debe clonar el repositorio, instalar las dependencias usando "flutter pub get" y correr el archivo main.dart en el dispositivo o emulador deseado

# Funciones

-Pedir permiso de notificaciones al iniciar la app
-Conseguir los datos de la API de COVID
-Enviar una notificación del pais deseado
-Conseguir la imagen de las banderas y mostrarla junto a la información
-Estructura de código sencilla y separada por partes
